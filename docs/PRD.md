# Product Requirements Document: Ramayana AI — Sanctum

## Vision
Ramayana AI is a sacred reflective space (Sanctum) where users interact with the timeless wisdom of the Ramayana through a Sage-guided intelligence system. It is an education and mythology platform designed to move beyond generic chatbots into a "mythology intelligence" ecosystem.

## Core Philosophy: "Sit. Ask. Reflect."
- **Sanctum Experience:** Not a chatbot, but a space for contemplation.
- **Sage-Guided:** Interactions are mediated by a "Sage" that ensures wisdom, scripture-style formatting, and moral context.
- **Character Universe:** Deep interaction with Ramayana characters (Rama, Sita, Hanuman) with consistent memory and persona.

## V1 Features (Current Phase)
- **Sanctum Interface:** Dark, sacred theme with warm gold accents and soft motion.
- **Sage Interaction:** Responses follow a "Reflection -> Meaning -> Context -> Takeaway" structure.
- **RAG Retrieval:** High-quality retrieval from scripture texts.
- **Lightweight Orchestrator:** Query classification and routing.
- **Timeline Explorer:** Visual journey through the Ramayana.

## Roadmap
- **V1:** Sanctum + Sage (Core RAG & Wisdom).
- **V2:** Character Temple (Individual character modes).
- **V3:** Daily Layer (Wisdom, quotes, reflections).
- **V4-V7:** Identity, Personality Matching, GeoLore, and Advanced Temple Intelligence.

## Non-Negotiables
- No chatbot appearance.
- No generic AI UI.
- No agent loops or autonomous planning in V1.
- Production-grade, modular architecture.
