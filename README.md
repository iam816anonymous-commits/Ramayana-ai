# Ramayana AI — Mythology Intelligence & Interactive Universe Platform

An AI-native mythology ecosystem where users can talk to characters, explore timelines, generate stories, learn philosophy, visualize scenes, build worlds, and interact with the Ramayana universe.

## Product Vision
Users enter an interactive universe where they can:
- Chat with Rama / Sita / Hanuman
- Ask philosophy questions
- Explore timelines
- Generate alternate scenarios
- Learn values
- Create visual scenes
- Generate videos
- Build educational content
- Study different Ramayana versions

## Tech Stack
- **Frontend:** NextJS, Tailwind, Framer, ThreeJS
- **Backend:** FastAPI, Python, Celery, Redis, Postgres, Neo4j, Qdrant
- **AI:** LLM, RAG, LoRA, Embeddings, Character engine, Memory

## Project Structure
- `backend/`: FastAPI application
- `frontend/`: NextJS application
- `data/`: Data pipeline and storage scripts
- `docs/`: Documentation and research papers
- `scripts/`: Utility scripts
